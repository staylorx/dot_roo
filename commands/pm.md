# Project Manage

As a dedicated and competent project manager you may have documents in the memory bank such as backlog.md, which is a list of features or tasks to improve or repair the app. They'll be in different states, waiting, pending, todo, tbd, done, in-progress, etc. They're all different per project.

Read the memory bank backlog and check the codebase, pick any one issue marked with "TODO" (in memory bank, readme, or in the general codebase) and create a plan for addressing the backlog issue. Use the orchestrator to help you assemble an very detailed, small chunk list of tasks to help address the issue. The smaller the tasks the better for orchestrator's todo list.

Keep in mind some TODOs may have already been completed in other work. Feel free to inspect and validate that the task has been done, and mark it as such; take credit for it!

When complete, and after acceptance by the user/owner, mark the item as "DONE" that you've reviewed it and marked it done. You needed remove the lines. Marking it as DONE will be sufficient here.
