# Tools

A non-exhaustive list of packages and tools we use and don't. Think of it as an allow-list and deny-list. Don't use packages on the deny-list, unless you ask first.

## We use:

For a variety of reasons (licenses, good contributors, recent updates) these are packages and tools we use.

- riverpod
- mocktail
- rdf_core
- equatable_mixin

## Tools we do not use:

Mostly for license reasons, but every now and then some other reason, we don't use these (or at least greatly prefer not to). Most of the time it comes down to not wanting to use build_runner (which is great btw, but it has a place).

- mockito
- copy_with_extension (do it manually)
- injectable
- freezed
