Always use fpdart.

Never try-catch; don't throw exceptions. The only, um, deviation to this are very low-level services like http, sembast, database, etc. that use exceptions as a matter of course. And then use `TaskEither.tryCatch`, wrap the exception as a Failure, and flow it out.

If you're reaching to return `Future<Either<Failure, SomeClass>>`, then use `TaskEither<Failure,SomeClass>` instead.

Never return `void` when Unit is appropriate in a return.
