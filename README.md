# .roo

My .roo folder. I clone this over my $USERHOME/.roo folder on new machines.

```bash
# $HOME or %HOME% or whatever. Opening your terminal might just default you here.
cd $HOME
git clone git@github.com:staylorx/dot_roo.git .roo
```

# Linux/macOS

~/.roo

# Windows

%USERPROFILE%.roo
